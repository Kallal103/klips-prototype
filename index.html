Tier Configuration & JWX Tag Mapping

Define tiers and map JWX content tags to control publisher access.

18 publishers

Top-tier partners with full content access across all broadcasters.

tier_level = premium ×
tier_level = preferred ×
tier_level = open ×
drm = true ×

Selected partners with mid-tier content access, sports highlights only.

tier_level = preferred ×
tier_level = open ×

Add rule

Open Exchange

144 publishers

Open web publishers with general content only. No DRM or sports.

JWX Tag Rules
tier_level = open ×
drm = false ×
Add rule
Content types: Entertainment, lifestyle, general news Broadcasters: All DRM: No

How Tag Mapping Works

JWX Content Tags (applied at upload)

tier_level VALUES: premium, preferred, open
content_type VALUES: sports, sports_highlights, news, entertainment, live_shows
broadcaster VALUES: ant1, mega, star, alpha
drm VALUES: true, false
expiry_date FORMAT: YYYY-MM-DD
→

KLIPS Tier Access Rules

Premium sees all content where tier_level IN (premium, preferred, open)
Preferred sees content where tier_level IN (preferred, open) AND drm = false
Open Exchange sees content where tier_level = open AND drm = false
Tags are applied by broadcasters when uploading content to JWX. The KLIPS portal reads these tags via the JWX Management API and filters content per publisher's tier assignment.
